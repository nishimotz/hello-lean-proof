# 型安全と証明は別の話

Lean は **プログラミング言語** であると同時に **証明支援系** でもある。
この 2 つの顔は同じ型検査器に支えられているため、初心者は混ぜて理解しがち。
混ぜると説明が壊れる。分けて考える。

---

## 1. 2 つは独立している

| | 型安全 | 証明 |
|---|---|---|
| 何を守るか | 値の使い方の誤り（型違い） | 主張が成り立つこと |
| 誰が判定するか | 型検査器 | 型検査器（同じ仕組み） |
| 失敗すると | コンパイルエラー | `unsolved goals`（証明が閉じない） |
| 例 | `Nat` に `String` を渡せない | `P ∧ Q` から `Q` が出せない |

**同じ検査器が両方を担っている**。ここが Lean の面白さであり、混乱の元。

型安全は「**間違った使い方をそもそも書けなくする**」話。
証明は「**主張が本当に成り立つかを機械に確かめさせる**」話。
目的も失敗の現れ方も別物。

---

## 2. 教材で実際に混ざった例

中2の合同証明を Lean に写すとき、最初にこう書いた（**誤り**）。

```lean
def Congruent (A B : Type) : Prop := Nonempty (A = B)

axiom angle_eq_of_congruent (A B : Type) (tA tB : Nat) :
  Congruent A B → tA = tB
```

角度を `Nat` にした。これには 2 種類のまずさが重なっている。

### (1) 型安全の側の失敗

`Nat` は 0 以上の整数。角度の型としては粗すぎる。

- 単位（度 / ラジアン）が型に無い
- 範囲（0〜360）を型で守れない。361 でも型検査が通る
- そもそも中2の合同では**角の大きさを計算しない**。「同じ角である」ことだけが言えればよい

`Nat` を選んだことで、**証明したいことより強い主張**になってしまった。
「合同なら角度の数値が同じ」は、「合同なら角が等しい」より強い。強い主張は示しにくく、しかも中2の答案には無い内容。

### (2) 証明の側は壊れていない

注目すべきは、`Nat` のままで**証明は通る**こと。

```lean
example (ABC DEF : Type) (tA tD : Nat) (h : Congruent ABC DEF) : tA = tD := by
  exact angle_eq_of_congruent ABC DEF tA tD h
```

（Lean 4.36.0 で実測、エラー・警告なし）

型の選び方は雑だが、**仮定から結論を導く構造は正しい**。
だから「型安全の失敗」と「証明の失敗」を切り分けられる。

---

## 3. 中2の教材で見せるべきは「証明」の側だけ

角度を `Nat` にするか `Real` にするかは、**数学的モデリングの話**。
中2の答案の構造（仮定 → 根拠 → 結論）を伝えたいなら、数の話は持ち込まない。

角度は**名札**でよい。

```lean
inductive Angle where
  | A | B | C | D | E | F
  deriving DecidableEq, Repr
```

角の大きさを比べないなら、数の型は不要。
`Angle.A = Angle.A` は「同じ角である」という**同一性**の主張で、中2の答案の `∠A = ∠A` とそのまま対応する。

---

## 4. 型安全を語りたいときの型の選び方

型安全の話をするなら、角度の型は**守りたい性質を型に書く**。

| 目的 | 型の選び方 | 何が守られるか |
|---|---|---|
| 名前だけ区別したい | `inductive Angle` | 別の角を混ぜられない |
| 数値として扱いたい | `Real` + 前提条件 `0 ≤ θ ∧ θ < 360` | 範囲外を弾ける（証明で担保） |
| 単位を間違えたくない | `Measure Deg` のような単位付き型 | 度とラジアンの取り違えを型で防ぐ |

**中2の教材** → 1 行目（名前だけ）
**型安全の章** → 3 行目（単位付き型）まで踏み込む価値がある

---

## 5. まとめ

- 型安全は「**書けなくする**」話。証明は「**確かめる**」話
- 同じ型検査器が担うので混ざりやすいが、目的も失敗の見え方も違う
- 教材で中2の合同を扱うなら、**角度は名札**にして証明の構造だけを見せる
- 型安全を語るなら、守りたい性質を型に書く。`Nat` のような「とりあえずの数値型」は選ばない

**一言**: 「型を雑に選んでも証明は通ることがある。それは型安全が失敗しているだけで、証明の話ではない。」
